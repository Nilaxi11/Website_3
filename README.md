# Skincare E-Commerce Website

A responsive skincare product e-commerce website built using HTML, CSS, and Bootstrap.  
This project focuses on modern UI design, responsive layouts, and creating an attractive online skincare shopping experience.

## 🌐 Live Demo

https://website-3-omega.vercel.app/

---

## 📖 About The Project

This project is a frontend skincare and beauty products website developed using HTML, CSS, and Bootstrap.  
The website includes product showcase sections, responsive layouts, and a clean user interface inspired by modern beauty and skincare brands.

The goal of this project was to practice frontend development skills and create a visually appealing e-commerce website design.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## ✨ Features

- Responsive e-commerce design
- Modern skincare product layout
- Clean navigation bar
- Product showcase sections
- Bootstrap components
- Mobile-friendly interface
